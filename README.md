# AFK Cinematics — Forge 1.20.1

Forge port of AFK Cinematics, based on the supplied `afk-cinematics-1.0.5+26.2.jar` reference. This repository targets Minecraft 1.20.1 and Forge 47.x.

The reference is a client-side Fabric mod. The port will preserve its inactivity detection, cinematic camera shots, settings, music behavior, and controls while replacing Fabric entrypoints and mixins with Forge-compatible client events and APIs.

Build with `./gradlew build` using Java 17.
